# Repository instructions

Before working in this repository, read [SCOPE.md](SCOPE.md) and follow its preview scope agreement. Recheck it before each implementation step and state how the step directly supports the agreed goal.

Treat older staging plans and backlog items as context, not authorization to expand scope. Record unrelated findings in a backlog without implementing them. If a necessary change crosses the agreement's boundaries, explain the specific blocker and obtain approval first.

Preserve unrelated local changes. Do not modify current production accounts, maps, database, routing, or site files. Follow any more specific instructions in the directories you work in.
