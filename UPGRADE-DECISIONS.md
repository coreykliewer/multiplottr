# Upgrade decisions for Corey

Prepared 2026-10-25 from local source and existing test evidence. All decisions below are open. New features, the AI bulk API, migration, service activation, and deployment remain paused.

“Original” means the imported source snapshot, not verified production behavior. “Local” means the isolated test implementation; its synthetic accounts do not replace WordPress. See [BASELINE-REVIEW.md](BASELINE-REVIEW.md) for test scope and [BASELINE-PRESERVATION.md](BASELINE-PRESERVATION.md) for source boundaries.

| Area | Original implementation evidence | Current local support | Potential data loss or changed behavior | Decision Corey needs to make |
| --- | --- | --- | --- | --- |

Presence is not end-to-end proof. | Basic colors/coordinates/notes persist; real placement tested. Older label plugins load. Local save validation uses a fixed palette; advanced styles lack round-trip proof. | Numbering, size, custom images, and labels may disappear or be rejected by the local model. | Which styles must be preserved exactly? If prioritized later, approve separate machine auth, consent, retry semantics, result statuses, quotas, and location-data handling. |

## Suggested review order

1. Set nonnegotiable preservation requirements: existing maps/URLs, descriptions, markers, groups, and geometry.
2. Decide production identity, entitlements, privacy, and embed access.
3. Choose required import/export/print workflows and supported map options.
4. Approve a compatibility and validation milestone with acceptance criteria; choose the redesign scope afterward. Keep AI bulk plotting deferred until explicitly authorized.

These decisions define scope. They do not authorize data migration or implementation. Production entry points, actual schemas, and deployed integrations still require separately authorized confirmation.
